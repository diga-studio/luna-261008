# threat-scan-planner

本地威胁扫描的文件选择模块（库）。读取本地文件系统，生成保存在内存中的
扫描清单；不负责文件内容检测。

## 使用

```ts
import { planScan } from "threat-scan-planner";

const manifest = planScan({
  roots: ["/work/a", "/work/b"],      // 最多 20 个扫描根目录
  whitelist: ["/work/a/cache"],       // 最多 200 条白名单路径
});

for (const entry of manifest.files) {
  // entry.path: 代表路径（分量最少，平局按 UTF-8 字节序最小）
  // entry.dev / entry.ino: 底层文件实体标识
}
```

输入均为已规范化的绝对路径，按大小写敏感的路径分量匹配。

## 语义

- 遍历普通目录并跟随文件、目录符号链接（包括指向扫描根之外的链接）；
  只有普通文件进入清单，悬空链接与其他文件类型不贡献文件。
- 候选路径保留逐层访问时使用的名称，不替换成链接目标路径。
- 白名单按路径分量边界排除完全相同的候选路径及其全部后代；只作用于
  访问路径，不作用于底层文件实体。
- 硬链接 / 符号链接指向同一底层文件时只输出一条记录；内容相同但彼此
  独立的文件分别输出。
- 代表路径在该实体所有合法候选路径中取分量总数最少者，平局取完整路径
  UTF-8 字节序最小者；结果与扫描根输入顺序、目录遍历顺序无关。

## 实现要点

遍历在 （目录实体， 白名单 trie 节点） 状态空间上按层进行：链接环与指数级
汇合的访问路线被折叠成有限状态，耗时与状态数成正比，而非访问路线数。
每个状态只保留帕累托最优的访问路径前沿，用于代表路径选择。文件系统
操作使用逐跳解析后的无符号链接路径，避免内核 ELOOP 限制。
