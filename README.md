# clinical-cost-allocation

临床服务成本分摊库（药品 / 检验 / 护理）。由上层财务模块直接以 TypeScript
函数调用，输入与结果均保存在内存中，不依赖数据库、网络或任何外部服务。

## 功能

将一批成本单据按部门权重一次性分摊，生成既能逐单据追溯、又能整批平衡的结果：

- 每张单据的实际分摊合计严格等于原金额（四位小数）；
- 每条实际分摊额只取理想额的向下或向上四位小数值；
- 每个部门的实际汇总只取理想汇总的向下或向上四位小数值，且与明细一致；
- 整批金额不增不减；
- 在所有满足条件的方案中，先使**部门汇总最大绝对偏差**全局最小，
  再使**全部明细绝对偏差之和**全局最小。

## 算法

理想分摊额以 1e-8 精度（BigInt）保存，绝不预先舍入。分摊问题被建模为
取整指派问题：每个单据/部门单元格只决定「是否向上取整」，单据行与部门列
的取整数量构成带上下界的平衡约束，通过

1. 对部门偏差上界做二分搜索（可行性由最大流判定）确定第一目标最优值；
2. 在该上界下求解最小费用流，确定第二目标最优的逐格取整方案。

## 使用

```ts
import { allocateCosts } from "clinical-cost-allocation";

const result = allocateCosts({
  departments: ["PHARM", "LAB", "NURSE"],
  documents: [
    {
      documentId: "inv-001",
      amount: "12.3400",           // 十进制文本，最多四位小数
      weights: [                    // 整数权重，合计必须为 10000
        { departmentId: "PHARM", weight: 5000 },
        { departmentId: "LAB", weight: 2500 },
        { departmentId: "NURSE", weight: 2500 },
      ],
    },
  ],
});

// result.details     逐单据 × 部门明细（含理想额、实际额、偏差、来源单据号）
// result.departments 部门汇总（与明细一致）
// result.totals      整批合计与两项最优性指标
```

## 构建与测试

只需 Node.js（>= 18）：

```sh
npm install
npm test
```

测试覆盖：题目给定的三张 0.0001 元单据场景（最优最大部门偏差 0.00006、
明细偏差之和 0.00034）、理想额恰为四位小数的批次、空批次、较大混合批次的
业务规则不变量、非法输入校验，以及与暴力枚举在 300 个随机小批次上的
最优性对拍。
