# SupplyPulse 短保原料补货规划库

单一原料、单一仓库的采购规划组件。获批预测已展开为每日原料需求，
本组件只决定采购，不调整生产需求。所有数量均为统一基本单位的非负整数。

## 规则

- 计划期 N 天（1..60），第 0 天为今天。
- 所有批次保质期固定 3 天：到货日及随后两天可用，到货日加 3 的当天开始前失效。
- 每天先移除过期批次，再接收当日固定供应与新采购，最后按到货日 FIFO 满足当日需求。
- 既有批次（到货日 -2、-1 或计划期内）不得取消或延期。
- 新采购只能在允许的日期到货；采购日 = 到货日 - leadTime，且不得早于第 0 天。
- 每个到货日最多一张新订单；数量为 packSize 的正整数倍且不小于 MOQ。
- 优化目标按优先级：总采购量最小，其次订单数最少。返回全局最优解。

## API

```ts
import { plan, replay } from "./src";

const result = plan(input);
// result.feasible === true 时: { orders, totalQuantity, orderCount }
// result.feasible === false 时: 不可行

const check = replay(input, orders);
// 从输入批次与订单重算每日消费、过期量和结余，并判断可行性。
```

## 求解方法

按批次年龄做动态规划：每日状态为「前日到货余量、昨日到货余量」，
状态上界由输入需求推导（超过保质窗口内需求的库存必然浪费），
逐日枚举合法订货量转移，成本按（总量, 订单数）字典序比较。
不枚举完整计划组合，60 天规模毫秒级完成。
