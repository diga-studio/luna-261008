# phrase-translate-kernel

本地短语表翻译内核（TypeScript 实现），只处理一个语言对。调用方提供词条和从
HTML 中抽取的文本节点字节流；HTML 解析、译文转义和缓存不属于本组件。

## API

```ts
import { compile, translate } from "./src/index.ts";

const table = compile([{ source: "你好", target: "hello" }]);   // 编译一次
for await (const bytes of translate(table, byteStream)) { ... } // 复用多次
```

- `compile(entries)`：编译词表，返回可复用的 `PhraseTable`。词条的
  `source`/`target` 必须非空，`source` 不重复（违反时抛错）。
- `translate(table, chunks)`：接收异步 UTF-8 字节流（每块 ≤ 4096 字节，块边界
  可落在多字节字符内部），返回异步 UTF-8 字节流。无论输入如何分块，输出拼接后
  与整段文本执行从左到右最长匹配的结果逐字节相同，且不等输入到齐即开始输出。

匹配语义：在当前位置选择以该位置起始的最长 `source`，输出其 `target` 并消费对应
输入；无匹配则原样保留一个 Unicode 码点。长度按码点计；精确匹配，不做归一化；
译文不再参与匹配。

## 设计

**编译**：把所有 `source` 按码点**反转**后建立 Aho-Corasick 自动机（trie +
失败链 + 字典链）。节点数 ≤ 源串总码点数 + 1，转移边存于一个以
`node * 2^21 + codePoint` 为键的 `Map`。编译时间与空间均为 O(M)。

**转换**：维护一个容量 2L 码点的未提交窗口（L 为最长 source 长度）。

1. 增量 UTF-8 解码把字节流变成码点流，块边界切开的多字节序列由解码器暂存。
2. 窗口每积满 2L 个码点，就从窗口末尾向开头做一次自动机扫描。扫描到位置 t
   时，自动机状态的字典链直接给出"以 t 起始的最长 source"（反转词表中以 t
   结尾的最长反转词），每个位置 O(1) 均摊、只记录最长一个命中。
3. 对窗口前半段（L 个位置）做从左到右贪心提交：有命中输出 `target` 并跳过
   对应码点，否则原样输出一个码点。任何 source 长度 ≤ L，起点在前半段的匹配
   必然完整落在 2L 窗口内，因此这些决定是最终决定，提交后丢弃已处理前缀。
4. 输入结束后，残余窗口按同样方式收尾（此时窗口即全部剩余输入）。

**复杂度**（M = 词条 source+target 总码点数，N = 输入码点数，R = 输出码点数，
L = 最长 source 码点数）：

- 编译时间、词表空间：O(M)。
- 每次转换时间：O(N + R)。反向扫描对每个码点做 O(1) 均摊的自动机转移（失败链
  深度论证），贪心提交每步至少消费一个码点；窗口扫描总量 ≤ 2N。
- 每次转换额外空间：O(L)。只保留 ≤ 2L 个未提交码点、两块 L 长度的命中暂存数组
  和 ≤ 4 字节的 UTF-8 残余；不积存完整输入、完整输出或已处理前缀。
- 输出延迟：未产出结果的已读输入 ≤ 2L 个码点（≤ 4L + 4096），调用方暂停供给时
  已确定的结果都已产出。

**为什么不会退化**：

- *反复长前缀试探*（如 source 为 8191 个 a 加 b、输入为长串 a）：反向词以 b
  开头，扫描每个 a 时自动机停在根节点，每码点 O(1)；一般地，失败链保证每个
  码点的转移均摊 O(1)，与 L 无关，绝不从每个起点重新试探前缀。
- *候选命中数量爆炸*（如 source 为 a¹…a¹⁹⁹⁹、输入为长串 a）：每个位置最多
  记录字典链给出的**最长一个**命中，不枚举全部候选；贪心提交每次跳过整个
  命中长度，而不是逐个候选比较。

## 测试

```sh
npm install   # 安装 devDependencies（typescript、@types/node）
npm test      # node:test 全部测试（Node ≥ 22.6，原生运行 TypeScript）
npm run typecheck
```

- `test/correctness.test.ts`：共享前缀、包含关系、多字节字符、被更长命中遮蔽的
  隐藏命中、输入结束时长短语兜底与残余保留；同一文本按整块、逐字节、随机边界
  供给结果一致，并与朴素参考实现逐字节相同；随机模糊测试。
- `test/stress.test.ts`：8191a+b 与 a¹…a¹⁹⁹⁹ 两组各 1MiB 输入的可重复压力
  测试，校验结果并分别记录编译与转换耗时；超长 source 跨窗口边界的匹配。
- `test/streaming.test.ts`：供给超过缓冲界限后暂停、观察到输出才继续的输入源，
  验证转换能推进且最终结果与整段转换一致；并验证未提交输入不超过 4L + 4096。
- `test/reuse.test.ts`：一次编译多次转换、并发转换互不影响、非法词条报错。
